# Бот для записи на автоматизации

![CI](https://github.com/automatorr192-dev/quiz-automation-bot/actions/workflows/ci.yml/badge.svg)

Telegram-бот задаёт владельцу малого бизнеса 7 вопросов и за две минуты выдаёт персональную карту автоматизаций: где утекает время, что автоматизировать первым и с чего начать на этой неделе.

**Бот → ссылка появится после деплоя**

<img src="docs/demo.gif" width="300" alt="Диалог с ботом: 7 вопросов с кнопками, карта автоматизаций для салона, ссылка на живое демо и запрос телефона">

*Реконструкция диалога: тексты, кнопки и прогресс взяты из кода бота, карта — настоящий ответ
модели из прогона эвалов для профиля «салон, работаю один, запись и напоминания».*

## Зачем

Владелец бизнеса чувствует, что тонет в рутине, но не знает, за что хвататься первым. Развёрнутый ответ на это стоит консультации, а типовые советы из интернета не учитывают его сегмент и размер команды.

Бот делает первый шаг бесплатно и за две минуты. Для меня это одновременно лид-магнит: каждый пройденный квиз приходит мне в Telegram вместе с ответами — видно, кто отвечает и что у него болит.

## Что закрывает из типового ТЗ на бот-квиз

| Чего просят | Как сделано |

| Строка в Google Sheets | дата, канал, имя, ник, телефон, источник и все ответы — через веб-приложение Apps Script |

| Защита бюджета на ИИ | суточный лимит карт на человека, перебор моделей |
| Устойчивость | состояние квиза и лимиты переживают передеплой, ошибки не роняют бота |

## Как работает

```
/start reels → 7 вопросов с кнопками (шаг назад, прогресс-бар)
             → каждый ответ пишется в воронку, бросивший получит одно напоминание
             → промпт с профилем бизнеса → модель через OpenRouter
             → карта автоматизаций пользователю, карточка лида мне в Telegram
             → «Оставить телефон» → лид с номером уходит в AI-CRM
```

Команды для владельца работают только в чате `ADMIN_CHAT_ID`: `/stats 7` — воронка за
неделю, `/leads 30` — Excel за месяц, `/quiz` — вопросы файлом на правку.

Неочевидное:

- **Перебор моделей.** `MODELS` — список через запятую, бот пробует по очереди, пока одна не ответит. С 18.10.2026 по умолчанию бесплатные NVIDIA Nemotron (50 запросов в сутки на аккаунт OpenRouter до покупки $10 кредитов), последней — копеечная платная DeepSeek V4 Flash. На Nemotron карта заметно слабее: советует сервисы, неудобные в России, и может выдумать название инструмента. Раньше запасные были только платными: прогон эвалов 17.10.2026 показал, что бесплатные запасные умерли (одна стала платной, у второй кончился суточный лимит), и при сбое основной модели карту было бы собрать не на чем. Тот же прогон нашёл, что человеку уходил сырой текст ошибки API с id аккаунта OpenRouter — теперь он только в логе.
- **Демо под боль.** После карты бот присылает ссылку на живой проект из портфолио: запись клиентов → Глянец, заявки и переписка → AI-CRM, отчёты → отчёт CRM. Ссылку ставит код по ответу «что отнимает время», а не модель — модель могла бы её выдумать.
- **Лид уходит в любом случае.** Если модель не ответила совсем, пользователь видит внятное сообщение вместо ошибки, но карточка лида мне всё равно приходит — ответы уже собраны, терять их незачем.
- **Состояние в файле, воронка в SQLite.** Незаконченный квиз и суточные лимиты лежат в `/data` и переживают передеплой. Воронка и лиды — в `/data/quiz.db`: отдельный сервер базы для бота на сотню человек в день был бы лишними деньгами каждый месяц.
- **В CRM лид уходит один раз.** Сразу, если человек оставил телефон, иначе через 10 минут с его ником. Отправить сразу и потом второй раз с телефоном значило бы две карточки на одного человека.
- **Телефон только свой.** Кнопка Telegram отдаёт номер владельца аккаунта; пересланный чужой контакт бот не принимает. Под кнопкой написано, зачем нужен номер.

## Где работает

Telegram-версия живёт на Cloudflare Workers ([worker/](worker/)), бесплатно и без своего
сервера. Python-версия осталась для MAX и эвалов: API MAX требует сертификат Минцифры,
которого нет в рантайме Workers.

Бесплатного хостинга, где бот на long polling работал бы круглосуточно без карты, не
осталось, а домашний ПК выключается. Worker процесс не держит: каждое нажатие Telegram сам
присылает на вебхук, и серверам Telegram блокировки Cloudflare в РФ не мешают.

- **Вебхук отвечает сразу, карту пишет Workflow.** Модель думает до пары минут, а у
  бесплатного Worker 10 мс процессора на вызов. Ожидание ответа сети процессор не тратит,
  поэтому запрос к модели — шаг Cloudflare Workflow. По той же причине Bot API вызывается
  напрямую, без библиотеки.
- **Состояние в D1.** Незаконченный квиз, воронка, лиды, суточные лимиты и присланный
  владельцем квиз лежат в SQLite у Cloudflare: памяти между сообщениями у Worker нет.
- **Крон раз в 5 минут:** напоминание бросившим квиз, догоняющая отправка лидов в CRM и
  таблицу, установка вебхука и описания бота. Вебхук ставит сам Worker, потому что с машины,
  с которой деплоят, `api.telegram.org` из РФ может не открываться.
- **Один контент на две версии.** Вопросы, тексты, промпт карты и ссылки на демо лежат в
  [content/](content/), их читают и Worker, и Python. Эвалы проверяют тот же промпт, что в бою.
- **Подделать апдейт нельзя.** Каждый запрос на вебхук несёт секрет из `setWebhook`, без него
  ответ 403.
- `/leads` в этой версии отдаёт CSV, который Excel открывает как таблицу: без библиотеки
  под xlsx.

```bash
cd worker && npm ci
npx wrangler login
npx wrangler d1 create quiz-bot                      # id базы → wrangler.jsonc
npx wrangler d1 migrations apply quiz-bot --remote
npx wrangler secret put TELEGRAM_BOT_TOKEN           # и остальные из secrets.required
npx wrangler deploy                                  # адрес → PUBLIC_URL, и deploy ещё раз
npm test                                             # vitest внутри рантайма Workers с локальной D1
```

Вебхук появится с ближайшим кроном. Python-бот с тем же токеном перейдёт на long polling и
снимет вебхук, поэтому Telegram-часть запускается только в одном месте.

## MAX

Если задан `MAX_BOT_TOKEN`, рядом с Telegram-ботом в том же процессе запускается версия
для MAX на long polling: те же вопросы и тексты, та же воронка, лиды и отправка в CRM и
таблицу. Идентификаторы пользователей MAX хранятся отрицательными, поэтому с телеграмными
не пересекаются, а напоминание бросившему квиз уходит в тот мессенджер, где он его бросил.

API MAX работает на сертификате Минцифры: корень `certs/russian_trusted_root_ca.pem`
подгружается к обычным корням, без него httpx не устанавливает соединение. Токен бота
выдают после модерации и только самозанятому, ИП или юрлицу.

## Google Sheets

В таблице: «Расширения → Apps Script», вставить код, «Развертывание → Новое → Веб-приложение»,
доступ «Все». Адрес развертывания — в `SHEETS_WEBHOOK_URL`, тот же токен — в `SHEETS_TOKEN`.

```js
const TOKEN = 'тот же, что SHEETS_TOKEN';

function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  if (data.token !== TOKEN) return ContentService.createTextOutput('forbidden');
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const keys = Object.keys(data.row);
  if (sheet.getLastRow() === 0) sheet.appendRow(keys);
  sheet.appendRow(keys.map((key) => data.row[key]));
  return ContentService.createTextOutput('ok');
}
```

Сервисный аккаунт Google и библиотека под Sheets API здесь не нужны: таблица заказчика
принимает строку сама, а бот только отправляет JSON. Строка уходит один раз — с телефоном
или через 10 минут без него, — и отдельно от CRM: если одна из двух сторон лежит, вторая не
получит дубль при повторе.

## Качество карты

Правильного ответа у карты нет, но качество измеримо. 16 профилей бизнеса в [evals/](evals/)
— от самозанятого «всё вручную» до команды 20+ с CRM; прогон `python evals/run_eval.py`.

- **Механика** — то, что ловит код: до 1500 знаков, без markdown, все три раздела, без сумм и
  цифр дохода, без призыва «напиши мне» (его добавляет бот).
- **Рубрика** — то, что ловит только чтение. Вторая модель (LLM-as-judge) ставит 1–5: опирается
  ли карта на ответы именно этого человека, конкретны ли шаги, честны ли обещания. Проход —
  не ниже 4 по всем трём. Оценка хранится с объяснением: судья тоже ошибается.

| Прогон | Карт прошло | Судья: опора на ответы / конкретность / честность |
|---|---|---|
| первый, 17.10.2026 | 14 из 16 (88%) | 4,9 / 4,9 / 4,8 |
| после правки промпта | **15 из 16 (94%)** | 4,9 / 4,9 / 4,9 |

Между прогонами в промпт добавлено одно правило: время оценивать скромно и под размер команды —
судья поймал карту, обещавшую самозанятому 10–15 часов экономии в неделю. Оставшийся провал —
карта длиннее лимита. Модель — DeepSeek V4 Flash, судья — она же.
