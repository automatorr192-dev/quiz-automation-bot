# Бот для записи на автоматизации

![CI](https://github.com/automatorr192-dev/quiz-automation-bot/actions/workflows/ci.yml/badge.svg)

Telegram-бот задаёт владельцу малого бизнеса 7 вопросов и за две минуты выдаёт персональную карту автоматизаций: где утекает время, что автоматизировать первым и с чего начать на этой неделе.

**Бот → ссылка появится после деплоя**

## Зачем

Владелец бизнеса чувствует, что тонет в рутине, но не знает, за что хвататься первым. Развёрнутый ответ на это стоит консультации, а типовые советы из интернета не учитывают его сегмент и размер команды.

Бот делает первый шаг бесплатно и за две минуты. Для меня это одновременно лид-магнит: каждый пройденный квиз приходит мне в Telegram вместе с ответами — видно, кто отвечает и что у него болит.

## Что закрывает из типового ТЗ на бот-квиз

| Чего просят | Как сделано |
|---|---|
| Квиз с кнопками, шаг назад, прогресс | 7 вопросов, «Назад», полоска прогресса |
| Персональный результат | карта автоматизаций от модели под ответы человека |
| Заявка менеджеру | карточка лида в Telegram сразу после квиза |
| Телефон клиента | кнопка «Оставить телефон» после результата, только свой номер |
| Заявки в CRM | подписанный вебхук в AI-CRM, оттуда в amoCRM и Битрикс24 |
| Дожим бросивших | одно напоминание через час с кнопкой «Продолжить» |
| Аналитика воронки | `/stats`: сколько начали, дошли до каждого вопроса, получили карту, оставили телефон |
| Источники трафика | deep-link `t.me/бот?start=reels` пишется в лид, отчёт по источникам |
| Выгрузка | `/leads` присылает Excel со всеми ответами |
| Защита бюджета на ИИ | суточный лимит карт на человека, перебор моделей |
| Устойчивость | состояние квиза и лимиты переживают передеплой, ошибки не роняют бота |

## Как работает

```
/start reels → 7 вопросов с кнопками (шаг назад, прогресс-бар)
             → каждый ответ пишется в воронку, бросивший получит одно напоминание
             → промпт с профилем бизнеса → модель через OpenRouter
             → карта автоматизаций пользователю, карточка лида мне в Telegram
             → «Оставить телефон» → лид с номером уходит в AI-CRM
```

Команды для владельца работают только в чате `ADMIN_CHAT_ID`: `/stats 7` — воронка за
неделю, `/leads 30` — Excel за месяц.

Неочевидное:

- **Перебор моделей.** `MODELS` — список через запятую, бот пробует по очереди, пока одна не ответит. Бесплатные модели OpenRouter регулярно перегружены, поэтому одна модель = регулярно неработающий бот.
- **Лид уходит в любом случае.** Если модель не ответила совсем, пользователь видит внятное сообщение вместо ошибки, но карточка лида мне всё равно приходит — ответы уже собраны, терять их незачем.
- **Состояние в файле, воронка в SQLite.** Незаконченный квиз и суточные лимиты лежат в `/data` и переживают передеплой. Воронка и лиды — в `/data/quiz.db`: отдельный сервер базы для бота на сотню человек в день был бы лишними деньгами каждый месяц.
- **В CRM лид уходит один раз.** Сразу, если человек оставил телефон, иначе через 10 минут с его ником. Отправить сразу и потом второй раз с телефоном значило бы две карточки на одного человека.
- **Телефон только свой.** Кнопка Telegram отдаёт номер владельца аккаунта; пересланный чужой контакт бот не принимает. Под кнопкой написано, зачем нужен номер.

## Стек

Python 3.11 · aiogram 3 · OpenRouter (OpenAI SDK) · SQLite · httpx · openpyxl · Docker · GitHub Actions

## Запуск

```bash
cp .env.example .env    # заполнить токены
docker compose up --build
```

Без Docker:

```bash
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
python bot.py
```

## Разработка

```bash
ruff check --fix .   # линт
ruff format .        # форматирование
pytest -q            # тесты
```
